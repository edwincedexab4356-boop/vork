    El corazón, en C++.

    Fragmento resumido del programa que corre en el Arduino de VORK 1.0 (se quitaron las líneas que guardan la hora de la alerta). El simulador de esta página sigue estas mismas reglas.

    AlarmaAntirrobo.inovoid actualizarEstado()
    void actualizarEstado() {
  unsigned long e = millis() - estadoDesde;
  switch (estado) {
    case RETARDO_SALIDA:
      if (e >= RETARDO_SALIDA_MS) { cambiarEstado(ARMADO); registrarEvento("ARMADO", 2); }
      break;
    case ARMADO:
      if (hayIntruso()) {
        distanciaDeteccion = distanciaCm;  // al sonar la alarma el intruso puede haberse movido
        cambiarEstado(RETARDO_ENTRADA);
        char txtDet[24];
        snprintf(txtDet, sizeof(txtDet), "DETECCION a %d cm", distanciaDeteccion);
        registrarEvento(txtDet, 4);  // aviso normal: la pantalla roja de la app es solo para la intrusion
      }
      break;
    case RETARDO_ENTRADA:
      if (e >= RETARDO_ENTRADA_MS) {
        cambiarEstado(ALARMA);
        char txt[24];
        snprintf(txt, sizeof(txt), "INTRUSION a %d cm", distanciaDeteccion);
        registrarEvento(txt, 5);
      }
      break;
    case ALARMA:
      if (e >= SIRENA_MAX_MS) { cambiarEstado(ARMADO); registrarEvento("FIN SIRENA 3 MIN", 3); }
      break;
    case SILENCIADA:
      if (e >= SILENCIO_MAX_MS) { cambiarEstado(ARMADO); registrarEvento("VIGILANDO DE NUEVO", 2); }
      break;
    default: break;
  }
}
    Sin delay(): el programa nunca se bloquea. Cada vuelta del loop() mide el tiempo con millis(), así puede leer el sensor, atender el Bluetooth y hacer sonar la sirena al mismo tiempo.

    La app oficial.

    La alarma real se controla con la app VORK para Android, conectada por Bluetooth. Cada persona entra con su propia clave.

    • PanelArmar, desarmar y silenciar con un toque.
    • AutoDibujo del auto con el sensor, la distancia en vivo y el estado de cada pieza.
    • ReportesEventos de hoy, 7 días, 30 días o todo; se pueden imprimir o guardar en PDF.
    • UsuariosAdministradores y usuarios, cada uno con su clave.
    • Hey VORKControl por voz, sin tocar el teléfono.
    • AlertaPantalla roja a pantalla completa aunque la app esté cerrada.
